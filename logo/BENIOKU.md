# Bedri Ayzet — Logo Seti

| Dosya | Nerede kullanılır |
|---|---|
| `bedri-ayzet-logo` | Ana logo: tabela, afiş, sosyal medya (açık zemin) |
| `bedri-ayzet-logo-koyu-zemin` | Koyu zeminli baskılar, ekranlar |
| `bedri-ayzet-logo-tek-renk` | Tişört baskısı, kaşe, fatura, tek renkli baskılar |
| `bedri-ayzet-yatay` / `-koyu-zemin` | Dar ve uzun alanlar: web sitesi üst kısmı, e-posta imzası |
| `bedri-ayzet-ikon` | Profil fotoğrafı (Instagram, WhatsApp, Google), uygulama simgesi |
| `bedri-ayzet-ikon-seffaf-koyu` | Koyu zemin üzerinde saydam ikon |

- **SVG** dosyaları vektördür; matbaaya ve tabelacıya bunları verin, her boyutta net basılır.
- **PNG** dosyaları (2000 px / ikon 1024 px) ekranda ve sosyal medyada kullanım içindir.
- Yazılar yola (path) çevrildiği için yazı tipi kurulu olmayan bilgisayarlarda da aynı görünür.

## Renkler

| Renk | HEX | RGB | Kullanım |
|---|---|---|---|
| Lacivert | `#0A2540` | 10, 37, 64 | Harfler, halter |
| Elektrik mavisi | `#12A8F0` | 18, 168, 240 | Vurgu, kavis, plaka şeridi |
| Koyu mavi | `#0B6FD6` | 11, 111, 214 | Kavis geçişi |
| Gri-mavi | `#4A5A6B` | 74, 90, 107 | "SPOR SALONU" yazısı |

Yazı tipi: **Montserrat** (ExtraBold / Black / SemiBold) — SIL Open Font License, ücretsiz ticari kullanım.
